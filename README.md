# 公司人员和薪酬管理系统

## 项目概述
这是一个小型公司人员和薪酬管理系统，为公司财务部门提供一个简易管理系统，能够在该公司发放薪水时，方便财务人员为公司各职工发放薪水并提供方便直观的工资统计报表。

## 功能特性

### 人员类型
小型公司主要有四类人员：
- **经理 (Manager)** - 等级4，固定月薪18000元
- **技术人员 (Technican)** - 等级3，按每小时120元领取月薪
- **推销员 (Saleman)** - 等级1，月薪按该推销员当月销售额的4%提成,底薪4000
- **销售经理 (Salemanager)** - 等级2，固定月薪5000元 + 所管辖部门当月销售总额的2%提成

### 系统功能
1. **员工信息录入** - 存储职工编号、姓名、级别、当月薪水等数据
2. **自动编号** - 员工编号从2001起自动生成，顺序加1
3. **等级设定** - 为所有人员设定级别功能
4. **薪资计算** - 根据不同职位类型自动计算月薪
5. **报表显示** - 显示信息和方便直观的工资统计报表

## 文件说明

- `Person.h/cpp` - 基类Person，定义职工的基本属性
- `Manager.h/cpp` - 经理类
- `Technican.h/cpp` - 技术人员类
- `Saleman.h/cpp` - 推销员类
- `Salemanager.h/cpp` - 销售经理类（多重继承）
- `main.cpp` - 主程序，包含用户交互界面

## 个人小结

### 经验


- **静态成员自动编号**：使用static成员变量`count`实现员工编号的自动递增，确保每个员工都有唯一的编号。

### 教训


- **虚析构函数的重要性**：基类必须声明虚析构函数，否则通过基类指针删除派生类对象时，只会调用基类的析构函数，导致派生类的资源无法正确释放。

- **多重继承的复杂性**：Salemanager类同时继承Manager和Saleman，需要使用虚继承来避免菱形继承问题，否则会导致Person基类被重复继承。

### 创新

- **友好的用户交互界面**：设计了清晰的菜单提示和分步骤的信息输入流程，用户体验良好。

- **灵活的类型选择**：用户可以在运行时动态选择要添加的员工类型，系统根据不同类型提示输入相应的数据（如技术人员的工作时间、推销员的销售额等）。

### 改进

- **增加更多管理功能**：可以添加删除员工、修改员工信息、按条件查询员工等功能，使系统更加完善。

- **异常处理**：添加输入验证和异常处理机制，防止用户输入非法数据导致程序崩溃（如输入非数字字符、负数等）。


---


### 输入注意事项
1. **员工总数**：输入正整数，建议不超过100人（避免输入过多数据）

2. **职位类型选择**：必须输入1-4之间的数字，其他输入会跳过该员工
